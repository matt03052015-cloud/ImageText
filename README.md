**ImageText – Unicode Dot Art Converter**

ImageText is a Python tool that converts images into recognizable Unicode text art using Braille-style characters such as ⣿, ⣤, ⠿, and ⠛. It lets you adjust the character width from 50 to 750 and change the contrast to improve details and shading. You can preview your artwork, copy it to your clipboard, or save it as a text file. It supports common image formats, including PNG, JPG, and WEBP, with an option to preserve transparent backgrounds.
